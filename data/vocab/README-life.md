# life-01 · 生活 · 興趣（일상과 취미）

獨立於通用詞庫的興趣模組。收的不是「該學的詞」，是**這位學習者真的會用到的詞**。

| 場景 | 詞 |
|---|---|
| 療癒 · 內在 | 힐링 · 위로 · 여유 · 설레다 · 다정하다 · 소소하다 · 혼자 |
| 生活品質 | 카페 · 산책 · 취향 · 취미 |
| 創作 · 自媒體 | 작품 · 영감 · 일기 · 글 · 브이로그 · 콘텐츠 · 편집 · 구독 · 촬영 |
| 追星 | 최애 · 덕질 · 컴백 · 가사 · 응원 |
| 角色 · 周邊 · 扭蛋 | 산리오 · 시나모롤 · 디즈니 · 굿즈 · 뽑기 · 인형 |
| 設計美感 | 디자인 · 감성 · 색감 · 소품 |
| 打掃 · 清潔 | 청소 · 정리 · 먼지 · 빨래 · 설거지 |
| 命理 · 運勢 | 사주 · 운세 · 점 · 타로 · 띠 · 행운 |

## 為什麼獨立成一個詞庫

vocab-01 是通用詞彙，daily-01 是入門日常。這批是**依興趣挑的**，
混進去會稀釋另外兩個詞庫的定位，也讓「今天學哪一庫」失去意義。
獨立之後，想背通用詞就選 vocab-01，想學能立刻用在自己生活裡的就選這裡。

## 收詞的判準

不是「這個主題該有的詞」，是「她會說出口或會聽到」的詞。
所以收 굿즈（周邊）不收 상품（商品）—— 韓國粉絲圈只說前者；
收 사주 不收 자미두수 —— 紫微斗數在韓國幾乎不用，對應的主流命理是四柱。

漢字詞特別標出與中文不同的：
청소＝淸掃、촬영＝撮影、구독＝購讀、소품＝小品、색감＝色感、인형＝人形。
這幾個猜中文會猜錯，正是學過中文的人最容易踩的地方。
